Context 工程與 Skill 架構五層論 工程演進

三大工程進化：AI 應用的思維躍遷

Prompt Engineering ➔ Context Engineering ➔ Loop Engineering

AI 開發已歷經三代變革：從第一代單向「提示詞工程（Prompt）」、第二代圍繞專案記憶的「脈絡工程（Context）」，邁向第三代具備自主反饋閉環的「迴圈工程（Loop）」。

  • 第一階段 Prompt Engineering：單次對話、依賴精美提示詞
  • 第二階段 Context Engineering：以檔案/記憶/架構為核心
  • 第三階段 Loop Engineering：具備自我修正與自動反饋閉環

  • SKILL.md = Agent 的大腦操作指引與任務觸發器
