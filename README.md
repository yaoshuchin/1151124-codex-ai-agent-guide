## 🎯 系統核心功能

1. **密碼門禁保護**：
   - 預設通關密碼：`nato`
   - 具備磨砂玻璃遮罩、錯誤震動反饋、`sessionStorage` / `localStorage` 狀態記憶與「重新上鎖」功能。
2. **多維布景主題切換**：
   - 淺色模式 (Light)
   - 深色模式 (Dark，預設科技黑)
   - 綠色模式 (Green，清新翡翠綠)
   - 藍色模式 (Blue，蔚藍海洋風)
3. **字型大小多段調節**：
   - 中 (標準 16px)
   - 大 (放大 18px)
   - 特大 (清晰 20px)
4. **多標籤分頁導覽系統**：
   - 🧭 **全部投影片總覽**：50 頁縮圖與詳細摘要，支援單元快篩與即時關鍵字搜尋。
   - 📚 **單元結構導讀**：6 大核心單元導讀與投影片分組。
   - 💻 **核心提示詞指令庫 (Prompt Studio)**：完整收錄 7 大核心 Prompt，支援一鍵複製到剪貼簿。
   - 🏗️ **Codex 五層金字塔架構**：AGENTS.md ➔ skills ➔ references ➔ scripts ➔ src 視覺化層級。
   - 🔗 **實戰教材與雲端資源包**：Google Docs 申請單、Google Sheets 財產檔、Drive 照片、LINE群與FB專頁。
5. **全螢幕互動播放器 (Slide Modal Viewer)**：
   - 點擊任一投影片卡片即可開啟高解析檢視器。
   - 支援鍵盤左右鍵 (`←` / `→`)、上一頁 / 下一頁切換與 `Esc` 退出。
   - 支援 WebP 輕量高速快取與自動回退機制。

## 🛠️ 本地執行方式

直接以瀏覽器開啟 `index.html` 即可瀏覽，或使用 Python 啟動本地靜態伺服器：

```bash
python -m http.server 8000
```
開啟瀏覽器前往：`http://localhost:8000`，輸入通行密碼 `nato` 即可體驗！
