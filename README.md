# AI Agent 時代來臨 · Codex 打造超級小幫手

> **講師**：橘子老師 · 2026 最新實戰研習簡報  
> **系統架構**：純前端響應式 Web 簡報引擎（支援 16:9 投影模式、白板塗鴉、圖文卡片閱讀、無障礙字級切換、四色布景與 GitHub Pages 零伺服器託管）  
> **通行密碼**：`nato`

---

## 🌟 專案亮點與核心特色

1. **全份 50 頁高解析度投影片無損呈現**：
   - 包含封面、三階段工程論、Codex 核心規格、試算表自動發信、財產報廢公文生成與雲端自動排程出題全流程。
2. **多維雙模式切換**：
   - 📺 **16:9 簡報投影模式**：等比劇院縮放、全螢幕播放、自動定時翻頁、縮圖抽屜、白板畫筆塗鴉。
   - 📖 **卡片式圖文閱讀模式**：條列重點清單、單元分類徽章、外部雲端素材一鍵直達、大圖燈箱放大。
3. **分頁標籤導航（5 大單元）**：
   - 🚀 **單元一：講師介紹與社群前言** (P1 ~ P5)
   - 🛠️ **單元二：Codex 基礎與指令工具** (P6 ~ P12)
   - 📐 **單元三：Context 工程與 Skill 架構五層論** (P13 ~ P25)
   - 📊 **單元四：實戰一 · 試算表與郵件通知** (P26 ~ P36)
   - ⚡ **單元五：實戰二與三 · 報廢單與排程出題** (P37 ~ P50)
4. **無障礙輔助與個人化體驗**：
   - 🔠 **字型大小**：中（預設）、大、特大（即時動態縮放）。
   - 🎨 **四色布景**：淺（清新高對比）、深（沉浸深藍黑）、綠（翡翠科技綠）、藍（深邃海洋藍）。
   - 💾 **狀態保持**：所有自訂配置與驗證狀態均自動保存於 `localStorage`。
5. **安全門禁防護 (Password Gate)**：
   - 採用 SHA-256 安全雜湊門禁卡片，通行密碼為 `nato`。
   - 提供「🔒 重新上鎖」按鈕隨時保護內容隱私。

## 🚀 本地快速啟動

雙擊執行根目錄的 `start.bat`，或在終端機中開啟：
```bash
start index.html
```
輸入通行碼 `nato` 即可解鎖全站內容。
